# Craft Market 3D - Backend

Welcome to the **Craft Market 3D** backend repository! This project serves as the server-side application of the Craft Market 3D platform, built using **NestJS**.

## 🚀 Features

## 🛠️ Tech Stack

- **Framework:** [NestJS](https://nestjs.com/)

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/thangvb168/craft-market-3d-backend.git
   ```

2. Navigate to the project directory:

   ```bash
   cd craft-market-3d-backend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file by copying `.env.example`:

   ```bash
   cp .env.example .env
   ```

5. Update `.env` with the correct environment variables.

## 🖥️ Running the Project

- Development mode:

  ```bash
  npm run dev
  ```

- Build for production:

  ```bash
  npm run build
  ```

- Start the production server:

  ```bash
  npm run start

  ```

The app will be available at `http://localhost:8000`.

## 🔗 Frontend Integration

This backend connects to the **Craft Market 3D frontend**. Ensure the frontend is running and correctly configured to interact with the backend API. Frontend repository: [Craft Market 3D Frontend](https://github.com/thangvb168/craft-market-3d-frontend.git).
